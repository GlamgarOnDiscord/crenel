Changes made for Crenel: shadcn/ui primitives replaced by Radix primitives and small local
equivalents, the AI SDK types replaced by local types, Streamdown/shiki/tokenlens removed,
French labels, status colours mapped to Crenel's palette (grey, amber, red), and the
ModelSelector rendered in a popover with an effort control instead of a dialog.
Each file carries a header naming the original component it comes from.
