# Kit de marque Crenel

| Fichier | Usage |
| --- | --- |
| `icon.svg` | Icône maître (vectorielle, Arrow/QuiverAI), source de toutes les déclinaisons. |
| `favicon.svg`, `favicon-16/32/48.png` | Favicon recadré sur la tête et la clé, lisible à 16 px. |
| `logo-horizontal-dark.png`, `logo-horizontal-light.png` | Logo complet : icône + logotype Mona Sans Wide 900 + carré ambre. |
| `logo-stacked-dark.png` | Logo empilé (icône au-dessus). |
| `og-image.png` | Image de partage 1200×630 (landing, réseaux). |
| `github-social.png` | Aperçu social du dépôt GitHub, 1280×640. |
| `readme-banner.png` | Bannière en tête du README. |
| `guide/01-planche.png` … `05-mockups.png` | Charte : planche de marque, zone de protection, tailles minimales et usages à éviter, typographie, mockups. |
| `mockups/` | Mockups photo (CC0, sources dans `mockups/SOURCES.md`). |
| `typo/` | Les deux études typo (10 polices, puis 10 paires). |

Les PNG sont rendus en ×2. Typo : Chubbo 700 (logo, titres) + Switzer 300/400 (texte), JetBrains Mono (code), Fontshare licence ITF gratuite. Couleurs : fond `#0B0C10`, texte `#ECEDF2`, accent ambre `#F6A821`, fond de l'icône pervenche `#8697EC`.
